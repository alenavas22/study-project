# Анализ данных металлоорганических каркасных структур (MOFs)

Репозиторий содержит проект по анализу базы данных атомных координат и структурных параметров металлоорганических каркасных структур (MOFs) на основе набора данных **[High-Throughput Comp. Screening of MOFs](https://kaggle.com)**, взятого с сайта kaggle.com.

Датасет содержит геометрические и физико-химические параметры металлоорганических каркасных структур. Данные могут быть применены для оценки потенциала MOFs в задачах:
* разделения и очистки веществ;
* катализа;
* создания функциональных материалов.

Размер датасета: 1,8 МБ  
Ссылка на датасет: [Датасет на Google Диске](https://google.com)

## Установка

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com
   cd study-project
   ```

2. Разверните окружение и установите зависимости из файла:
   ```bash
   uv sync --frozen
   ```

## Пакет `etl`

В директории `src/etl` находится  ETL-пакет, обеспечивающий полный цикл подготовки данных:
1. **Extract (`extract.py`)** - скачивает исходный файл `dataset.csv` с Google Диска (если он отсутствует локально) и считывает его в DataFrame.
2. **Transform (`transform.py`)** - приводит столбцы к нужным типам данных (`str`, `float32`, `category`, `bool`) и выполняет валидацию таблицы.
3. **Load (`load.py`)** - сохраняет обработанный DataFrame в формат `.parquet`, записывает первые 100 строк в удаленную базу данных PostgreSQL (таблица `vasilenkoav`) и проверяет корректность записи.
4. **Main (`main.py`)** - запускает весь цикл обработки и принимает имя файла датасета в качестве аргумента командной строки.

Запуск пакета:
```bash
uv run etl dataset.csv
```

## Запуск скрипта `data_loader.py` 

1. Cкачивает исходный файл `dataset.csv` с Google Диска (если он отсутствует локально).
2. Выводит первые 10 строк датасета.
3. Считывает таблицу и приводит столбцы к правильным типам данных (`str`, `float32`, `category`, `bool`) для уменьшения занимаемой памяти.
4. Сохраняет DataFrame в формат `.parquet` (если файл `dataset.parquet` ещё не создан).

Запуск скрипта:
```bash
uv run python scripts/data_loader.py
```

## Работа с базами данных 

Для работы с базами данных используются библиотеки `sqlalchemy`, `psycopg2-binary` и `python-dotenv`. Все конфиденциальные данные подключения вынесены в файл `.env`, который добавлен в `.gitignore`.

### 1. Чтение учетных записей `read_creds.py`

Скрипт предназначен для чтения файла базы данных SQLite и вывода доступных учетных записей для подключения к удаленному серверу.

Запуск скрипта:
```bash
uv run python scripts/read_creds.py
```

### 2. Запись данных в удаленную БД `write_to_db.py`

Скрипт выполняет загрузку данных в удаленную базу данных PostgreSQL:
1. Считывает параметры доступа из файла `.env`.
2. Загружает файл `dataset.parquet`.
3. Выделяет первые 100 строк датасета.
4. Создает подключение к удаленному серверу и записывает данные в таблицу `vasilenkoav`.

Запуск скрипта:
```bash
uv run python scripts/write_to_db.py
```
