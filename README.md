# study-project
Репозиторий содержит проект по анализу базы данных атомных координат и структурных параметров металлоорганических каркасных структур (MOFs) на основе набора данных **High-Throughput Comp. Screening of MOFs**, взятых с сайта kaggle.com.
Датасет содержит геометрические и физико-химические параметры металл-органических каркасных структур. Данные могут быть применены для оценки потенциала MOFs в задачах разделения и очистки веществ, катализа и создания функциональных материалов.
